# VivaChat
MVP funcional de mensajería en tiempo real.

## Ejecutar
1. `npm install`
2. `npm start`
3. Abrir el puerto 3000.

En Replit: crea/importa este proyecto y usa `npm start` como comando de ejecución.

Incluye registro/login, SQLite, chats en tiempo real con Socket.IO, archivos hasta 15 MB y PWA básica.

Para producción: cambiar JWT_SECRET por un secreto fuerte, usar HTTPS, almacenamiento de archivos externo, backups, moderación, recuperación de cuenta, verificación de correo/teléfono, cifrado de extremo a extremo y revisión de seguridad.
